# Data Directory

Place your dataset files here before running the notebook.

## Required Files

| File       | Description                     |
|------------|---------------------------------|
| `train.csv` | Training dataset               |
| `test.csv`  | Test dataset for predictions   |

## Notes

- Raw data goes in `data/raw/` (ignored by git)
- Processed data goes in `data/processed/` (ignored by git)
- The root `data/` folder is for documentation only
